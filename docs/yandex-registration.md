# Общая регистрация через Яндекс и Google

Публичная страница `/social-registration` дополняет подтверждённый сервером профиль; `/yandex-registration` остаётся совместимым маршрутом.
Использует существующий runtime REACT_APP_BACKEND_URI для gateway; адрес SSO получает через `/oauth2/social/config`.
Профиль загружается через `/client/social/profile`, регистрация отправляется на `/client/social/registration`.
Секреты провайдеров во фронтенд не передаются. Требуется совместимый API из backend PR.

SSO: FRONTEND_URI должен точно совпадать с origin сайта. SSO и gateway: YANDEX_LOGIN_ENABLED=true,
YANDEX_REDIRECT_URI — публичный callback SSO. Настройки не задаются через параметры URL страницы.
POST регистрации защищён сессией SSO и CSRF, три согласия обязательны на обеих сторонах.
После регистрации требуется активация аккаунта администратором; повторный вход начинается с главной страницы.
Полный текст соглашения доступен в модальном окне, закрывается крестиком или Escape.

Форма оформлена по макету Figma для десктопа и телефона: Telegram username без @, необязательный телефон,
роль и три обязательных согласия. Номер из профиля провайдера подставляется автоматически и доступен
для исправления; перед отправкой пробелы, скобки и дефисы удаляются. Номер не считается подтверждённым
TrackMe и не используется для объединения аккаунтов.
Для телефона Яндекса нужны право «Номер телефона» в кабинете приложения и YANDEX_PHONE_ENABLED=true у SSO.
Для телефона Google нужны People API, GOOGLE_PHONE_ENABLED=true и выданное пользователем право
user.phonenumbers.read; наличие номера в ответе провайдера не гарантируется.
Экран «Заявка принята» сообщает об ожидании активации администратором и не обещает отправку письма.
