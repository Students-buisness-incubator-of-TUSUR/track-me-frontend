# Регистрация через Яндекс

Публичная страница `/yandex-registration` дополняет подтверждённый сервером профиль.
Использует существующий runtime REACT_APP_BACKEND_URI для gateway; адрес SSO получает через `/oauth2/yandex/config`.
Секреты Яндекса во фронтенд не передаются. Требуется совместимый API из backend PR.

SSO: FRONTEND_URI должен точно совпадать с origin сайта. SSO и gateway: YANDEX_LOGIN_ENABLED=true,
YANDEX_REDIRECT_URI — публичный callback SSO. Настройки не задаются через параметры URL страницы.
POST регистрации защищён сессией SSO и CSRF, три согласия обязательны на обеих сторонах.
После регистрации требуется активация аккаунта администратором; повторный вход начинается с главной страницы.
Полный текст соглашения доступен в модальном окне, закрывается крестиком или Escape.
